# Olist E-Commerce Sales & Customer Analytics

This project analyzes the Olist Brazilian E-Commerce dataset to understand sales, customers, products, sellers, payments, reviews, and delivery performance.

I built the project as an end-to-end analytics workflow using **Python, PostgreSQL, SQL, and Power BI**.

## What I Worked On

- Validated and cleaned the raw data using Python
- Stored and managed the data in PostgreSQL
- Created SQL tables, indexes, and analytical views
- Performed exploratory data analysis using Pandas and Matplotlib
- Built an interactive Power BI dashboard
- Created KPIs for revenue, orders, AOV, reviews, and delivery performance

## Tools Used

**Python | Pandas | NumPy | Matplotlib | PostgreSQL | SQL | Power BI | DAX**
